# Flights on the Trip Plan — Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (or subagent-driven execution) task-by-task.

**Goal:** Show up to 3 real Amadeus flight offers for every transition in a trip plan — home→first leg, inter-leg, last leg→home — degrading quietly when the key is missing or the API fails.

**Architecture:** Pure query-derivation + response normalization in `src/lib/flights.ts`; server-only Amadeus OAuth client in `src/lib/amadeus.ts`; the app's first route handler at `/api/flights`; a client `FlightStrip` per transition on `/trip/results`; optional "Flying from" IATA field on `/trip`. One migration adds `iata_code` to destinations.

**Tech stack:** Next.js 16 route handlers (READ `node_modules/next/dist/docs/` on route handlers before writing one — this Next version deviates from training data, per AGENTS.md), Amadeus Self-Service test API, Vitest, Playwright (with `page.route()` stubbing — CI has no Amadeus key).

**Design doc:** `docs/plans/2026-09-01-flights-design.md`. Conventions: `*.test.ts` Vitest / `*.spec.ts` Playwright, LEARNING NOTE house style, worktree rules as before.

**Env contract (server-only, never `NEXT_PUBLIC_`):** `DUFFEL_ACCESS_TOKEN` in `.env.local` (the user adds it; it may be ABSENT during implementation — everything must work without it except live offers). Listed in `.env.example` with a comment saying flights are optional. *(Tasks 1–4 were built against `AMADEUS_CLIENT_ID`/`AMADEUS_CLIENT_SECRET`; Task 5 replaced them — the Amadeus references below are history.)*

```ts
// --- Flights ---------------------------------------------------------------

/** One flight search: where from, where to, on what day. */
export interface FlightQuery {
  origin: string; // IATA
  dest: string; //   IATA
  date: string; //   "YYYY-MM-DD"
}

export interface FlightSegment {
  from: string;
  to: string;
  departAt: string; // ISO datetime, local to the airport
  arriveAt: string;
  carrier: string; //  2-letter airline code
  flightNumber: string;
}

export interface FlightOffer {
  price: string; //    e.g. "412.60" — string, exactly as the API quotes it
  currency: string;
  stops: number;
  duration: string; // ISO 8601 duration, e.g. "PT7H25M"
  segments: FlightSegment[];
}
```

### Task 2: Pure flight logic + tests (TDD)

**Files:** create `src/lib/flights.ts`, `tests/unit/flights.test.ts`, `tests/unit/fixtures/amadeus-flight-offers.json`.

`flightQueries(plan: TripPlan, homeAirport?: string): FlightQuery[]`:
- Inter-leg transitions always: origin = leg i's `destination.iataCode`, dest = leg i+1's, date = leg i+1's `startDate` (the arrival/travel day).
- With a valid `homeAirport` (matches `/^[A-Za-z]{3}$/`, uppercase it): prepend home→first leg on the trip's first day and append last leg→home on the trip's last day (`legs.at(-1)!.endDate`).
- Invalid/absent home airport → transitions only (no throw).

`normalizeOffers(apiJson: unknown): FlightOffer[]`: map Amadeus `data[]` → price `.price.grandTotal` + `.price.currency`, first itinerary's `duration` and `segments[]` (`carrierCode`, `number`, `departure.iataCode/at`, `arrival.iataCode/at`), `stops = segments.length - 1`. Defensive: skip malformed entries rather than throwing; empty/garbage input → `[]`.

### Task 3: Amadeus client + route handler

**Files:** create `src/lib/amadeus.ts`, `src/app/api/flights/route.ts`; modify `.env.example`; add token-cache test to `tests/unit/flights.test.ts`.

`amadeus.ts` (server-only; add the LEARNING NOTE explaining why these env vars are NOT `NEXT_PUBLIC_` and why missing-key degrades instead of throwing, contrasting with supabase.ts):

```ts
import { normalizeOffers } from "./flights";
import type { FlightOffer } from "./types";

const BASE = "https://test.api.amadeus.com";

export function amadeusConfigured(): boolean {
  return Boolean(process.env.AMADEUS_CLIENT_ID && process.env.AMADEUS_CLIENT_SECRET);
}

let cachedToken: { token: string; expiresAt: number } | null = null;

async function getToken(): Promise<string> {
  if (cachedToken && Date.now() < cachedToken.expiresAt) return cachedToken.token;
  const res = await fetch(`${BASE}/v1/security/oauth2/token`, {
    method: "POST",
    headers: { "Content-Type": "application/x-www-form-urlencoded" },
    body: new URLSearchParams({
      grant_type: "client_credentials",
      client_id: process.env.AMADEUS_CLIENT_ID!,
      client_secret: process.env.AMADEUS_CLIENT_SECRET!,
    }),
  });
  if (!res.ok) throw new Error(`Amadeus auth failed: ${res.status}`);
  const json = await res.json();
  // Refresh 60s early so a token never expires mid-request.
  cachedToken = { token: json.access_token, expiresAt: Date.now() + (json.expires_in - 60) * 1000 };
  return cachedToken.token;
}

/** Test hook: forget the cached token. */
export function resetTokenCache(): void {
  cachedToken = null;
}

export async function searchFlights(origin: string, dest: string, date: string): Promise<FlightOffer[]> {
  const token = await getToken();
  const params = new URLSearchParams({
    originLocationCode: origin,
    destinationLocationCode: dest,
    departureDate: date,
    adults: "1",
    max: "3",
    currencyCode: "USD",
  });
  const res = await fetch(`${BASE}/v2/shopping/flight-offers?${params}`, {
    headers: { Authorization: `Bearer ${token}` },
  });
  if (!res.ok) throw new Error(`Amadeus search failed: ${res.status}`);
  return normalizeOffers(await res.json());
}
```

Route handler `src/app/api/flights/route.ts` — READ the Next 16 route-handler doc in `node_modules/next/dist/docs/` first, then:

```ts
import { amadeusConfigured, searchFlights } from "@/lib/amadeus";

const IATA = /^[A-Z]{3}$/;
const DAY = /^\d{4}-\d{2}-\d{2}$/;

export async function GET(request: Request) {
  const { searchParams } = new URL(request.url);
  const origin = (searchParams.get("origin") ?? "").toUpperCase();
  const dest = (searchParams.get("dest") ?? "").toUpperCase();
  const date = searchParams.get("date") ?? "";
  if (!IATA.test(origin) || !IATA.test(dest) || !DAY.test(date)) {
    return Response.json({ error: "origin, dest (IATA) and date (YYYY-MM-DD) are required" }, { status: 400 });
  }
  if (!amadeusConfigured()) {
    return Response.json({ available: false as const });
  }
  try {
    const offers = await searchFlights(origin, dest, date);
    return Response.json(
      { available: true as const, offers },
      { headers: { "Cache-Control": "public, s-maxage=600, stale-while-revalidate=600" } },
    );
  } catch (error) {
    console.error("flight search failed:", error); // server log only — never echo Amadeus errors to the client
    return Response.json({ available: false as const });
  }
}
```
